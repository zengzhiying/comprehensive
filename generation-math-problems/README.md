# 100以内加减法练习卷生成器

生成一张 A4 尺寸（300 DPI）的加减法练习卷图片，可直接打印使用。

## 环境要求

- Python 3
- Pillow

```bash
pip install Pillow
```

## 使用方法

```bash
python3 main.py
```

按提示输入：

```
请输入题目数量(20~100)：50
是否添加题号？(y/N)：y
```

在当前目录生成 `exercise.png`，并打印版面信息：

```
已生成：exercise.png（50 题，4 列 × 13 行，字号 62px）
```

也可以直接调用函数，跳过交互：

```python
from main import generate_exam

generate_exam(50, "exercise.png", numbered=True)
```

| 参数 | 说明 |
| --- | --- |
| `count` | 题目数量，必须在 20~100 之间，否则抛 `ValueError` |
| `output` | 输出图片路径 |
| `numbered` | 是否在每题前添加题号，默认 `False` |

## 题目规则

- 随机生成加法或减法，操作数在 0~100 之间，结果保证非负
- 减法：减数不能为 0，且不大于被减数（不会出现「减 0」或负数结果）
- 加法：两个加数不能同时为 0，且和不超过 100

## 不重复保证

每次生成时先枚举全部合法算式（共 7650 道）构成题库，再用无放回抽样取出所需题量，
因此**同一份试卷中不会出现重复的题目**。

去重按「同一道题」判断，而非题面字符串：

- 加法交换律下 `3 + 5` 与 `5 + 3` 视为同一道题，只出一道，书写顺序随机
- 减法 `7 - 3` 与 `3 - 7` 结果不同，属于两道题，各自保留

题库容量 7650 远大于单份试卷的上限 100 题，无需担心题量不足。

## 版面说明

脚本会枚举 1~6 列的所有分栏方式，在「最长题目横向铺得够满」且「行距不过分稀疏」的布局中选出字号最大的一个，因此题量变化时字号和分栏会自动调整。

图片尺寸、页边距、字号上下限、列数上限等参数集中在文件顶部的「配置」区，可按需修改：

| 常量 | 含义 |
| --- | --- |
| `IMAGE_WIDTH` / `IMAGE_HEIGHT` | 图片尺寸，默认 A4 300DPI（2480 × 3508） |
| `MARGIN_X` / `MARGIN_BOTTOM` | 左右 / 底部页边距 |
| `MAX_FONT_SIZE` | 题目字号上限 |
| `MAX_COLUMNS` | 最多分几列 |
| `TITLE` | 试卷标题 |

## 字体

脚本按顺序查找系统中文字体，使用第一个可用的：

- Linux：`NotoSansCJK-Regular.ttc` / `NotoSerifCJK-Regular.ttc`
- macOS：`PingFang.ttc`
- Windows：`msyh.ttc` / `simhei.ttf` / `simsun.ttc`

若都未找到，会打印警告并回退到默认字体（汉字显示为方框）。要使用其他字体，在 `load_font()` 的 `candidates` 列表开头添加 `(字体路径, ttc 子字体索引)` 即可，`.ttf` 文件索引填 0。
